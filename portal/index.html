무거운 의존성 없이 단일 Rust 바이너리로 동작합니다. 도메인 연결, SSL 인증서, PHP 다중 버전 스위칭, Rust/Python/Node 앱 관리, 내장 멀티 DB 스튜디오까지 한 화면에서 제어하세요.

curl -sSL https://raw.githubusercontent.com/1clickmake/CHost/main/install.sh | sudo bash
개발자 문서 보기 포럼 게시판 소스코드 (GitHub)

핵심 아키텍처

초경량 단일 바이너리

Axum과 Tokio 기반 단일 바이너리로 메모리 20MB 미만으로 동작하며 Python이나 Docker 데몬을 강제하지 않습니다.

도메인 및 SSL 자동화

/www/wwwroot 경로 기반 사이트 생성, Nginx 리버스 프록시 설정, Certbot HTTPS 발급을 클릭 한 번으로 처리합니다.

PHP 다중 버전 10초 설치

ondrej/php 패키지 기반으로 PHP 7.4부터 8.4까지 빠르게 설치하고 사이트별로 즉시 버전을 전환합니다.

언어 프리셋 앱 매니저

Rust, Python, Node.js, PHP 앱을 systemd 서비스로 등록해 패널 부하 증가 없이 안정적으로 실행합니다.

내장 멀티 DB 스튜디오

phpMyAdmin 설치 없이 패널 내부에서 SQLite와 MySQL/MariaDB 테이블 조회, SQL 실행, 백업을 수행합니다.

안전한 로그 및 저장 공간 관리

보관 기간별 로그 로테이션(copytruncate), 예상 확보 용량 미리보기, DB 및 업로드 폴더 보호 화이트리스트를 제공합니다.
