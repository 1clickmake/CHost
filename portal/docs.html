CHost 공식 개발자 가이드 & 사용자 매뉴얼

CHost (씨호스트)는 초보자도 마우스 클릭 몇 번으로 Nginx/Apache, Node.js, Next.js, Python, PHP, Rust, MariaDB, PostgreSQL을 손쉽게 운영할 수 있도록 제작된 초경량 한국형 모던 웹 서버 관리 패널입니다.

💡 CHost의 3대 핵심 철학
1. 극강의 가벼움: 순수 Rust 싱글 바이너리로 메모리 점유율 30MB 이하, 백그라운드 리소스 소모 제로.
2. 초보자 친화적 자동화: 도메인만 넣으면 Nginx 리버스 프록시, systemd 데몬화, 무료 SSL(Let's Encrypt) 자동 발급.
3. Open-Core Pro 완성도: 원클릭 Git 롤백, AI 에러 닥터, S3 원격 백업, 멀티 서버 모니터링 탑재.

🚀 1줄 빠른 설치 (Linux)

Ubuntu 22.04/24.04, Debian 11/12, Rocky Linux, AlmaLinux, Amazon Linux 2023 등 대부분의 최신 리눅스 배포판을 완벽히 지원합니다.

curl -sSL https://raw.githubusercontent.com/1clickmake/CHost/main/install.sh | sudo bash

설치 스크립트는 서버 아키텍처(x86_64 / ARM64)를 자동 감지하여 /opt/chost에 바이너리를 배치하고, 무작위 관리자 비밀번호를 생성한 후 systemd 서비스를 즉시 가동합니다.

🔑 초기 비밀번호 확인 방법
설치 완료 후 콘솔 화면에 출력되며, 언제든 아래 명령어로 다시 확인할 수 있습니다:
sudo cat /var/lib/chost/init_password.txt

⚡ 초기 접속 및 기본 보안

웹 브라우저를 열고 http://서버IP:8800 으로 접속하여 초기 비밀번호를 입력하면 바로 대시보드로 이동합니다.

보안 권장사항: 로그인 직후 사이드바의 [⚙️ 설정] 메뉴로 이동하여 1) 관리자 비밀번호 변경, 2) 2단계 인증(TOTP OTP), 3) 비밀 접속 경로(/my-secret)를 설정하는 것을 강력히 권장합니다.

📊 대시보드 (Dashboard)

서버의 전반적인 건강 상태와 현재 서비스 중인 사이트/앱, 설치된 런타임 현황을 실시간으로 요약 브리핑합니다.

대시보드 실시간 모니터링 화면 (tab1_dashboard.png)

주요 기능

  • CPU / RAM / Disk / Uptime 게이지: 서버 리소스를 1초 단위로 감시하며, 디스크가 80%를 넘으면 즉시 경고와 함께 [대용량 폴더 분석] 버튼이 활성화됩니다.
  • 실행 중인 사이트 / 앱 상태 카드: 도메인별 온라인/오프라인 상태 및 프록시 포트, systemd 데몬 상태를 시각화합니다.
  • 설치된 서버 패키지 & 런타임: Nginx, MariaDB, Node.js, Python 등의 설치 및 실행 유무를 확인합니다.

⚙️ 설정 센터 (Settings Hub)

패널 관리자 보안, 포트 방화벽, 장애 알림, 보안 접속 경로, 초기화 퀴즈 등 서버 운영에 필수적인 설정을 한곳에서 총괄합니다.

설정 센터 상세 화면 (tab2_settings.png)

설정 항목 가이드

  • 🔐 패널 관리자 비밀번호 변경: Argon2id 단방향 암호화로 안전하게 새 비밀번호를 저장합니다.
  • 🔔 장애·리소스 알림: 디스크 90% 초과, 사이트 다운, SSL 만료 14일 전에 Slack/Discord 웹훅 또는 텔레그램 봇으로 즉시 통보합니다.
  • 🛡️ 방화벽 (UFW): 버튼 한 번으로 SSH, 웹(80/443), 패널 포트만 열고 불필요한 포트를 차단합니다.
  • 📱 2단계 인증 (OTP): Google Authenticator 앱으로 로그인 시 6자리 일회용 비밀번호를 요구합니다.
  • 🌍 접속 IP 제한: 관리자 IP(또는 대역)에서만 패널 로그인이 가능하도록 화이트리스트를 구성합니다.
  • 🚪 보안 접속 경로: 기본 / 경로 대신 /admin-secret-2026 같은 임의의 경로로만 로그인 창이 열리도록 잠급니다.

🌐 사이트 및 도메인 관리 (Sites)

도메인 연결, 가상 호스트 생성, Let's Encrypt SSL 무료 발급, 서브도메인, PHP 버전 스위칭을 전자동으로 처리합니다.

사이트 및 도메인 관리 화면 (tab3_sites.png)

주요 편의 기능

  • 듀얼 웹서버 전환: Nginx와 Apache2 중 원하는 엔진으로 원클릭 스위칭하며, 기존 설정 파일을 보존한 채 안전하게 마이그레이션합니다.
  • 원클릭 무료 SSL: Certbot 연동으로 https:// 인증서를 발급하고 매월 자동 갱신합니다.
  • 다중 PHP 버전 선택: 사이트마다 PHP 7.4, 8.0, 8.1, 8.2, 8.3, 8.4 중 최적의 버전을 독립 지정할 수 있습니다.
  • 공용 vendor 엔진: 그누보드7, 라라벨 프로젝트 생성 시 공유 vendor 디렉터리를 연결하여 디스크 용량을 90% 이상 절약합니다.

⚙️ 앱 프로세스 관리 (App Processes)

Node.js, Next.js, Python FastAPI, Go, Rust 등 백엔드 애플리케이션을 리버스 프록시와 결합하고 systemd 서비스로 안정적으로 구동합니다.

앱 프로세스 관리 화면 (tab4_apps.png)

주요 기능

  • 스마트 헬스체크: 앱 기동 후 127.0.0.1:PORT 로 직접 HTTP 프로브를 시도하여 정상 응답을 확인할 때까지 방문자에게 정적 준비 중 페이지를 보여줍니다.
  • 실시간 로그 스트리밍: journalctl -u chost-app-* 로그를 실시간으로 모니터링하여 크래시 원인을 빠르게 파악할 수 있습니다.

🗄️ 멀티 DB 스튜디오 (Database Studio)

MariaDB, PostgreSQL, SQLite를 하나의 패널에서 관리하며, 웹 기반 쿼리 실행, 사용자 계정 생성, 백업 및 CSV 다운로드를 지원합니다.

멀티 DB 스튜디오 화면 (tab5_db.png)

주요 기능

  • 웹 쿼리 에디터: 테이블 스키마 확인, SQL 질의 실행, 결과 테이블 확인.
  • UTF-8 BOM CSV 내보내기: 엑셀에서 한글이 깨지지 않는 표준 CSV 포맷으로 테이블 데이터를 즉시 다운로드합니다.
  • 예약 자동 백업: 매일 정해진 시각(기본 03시)에 모든 DB 덤프와 웹 소스, 패널 설정을 /www/backup에 압축 보관합니다.

🧹 저장 공간 및 로그 보관 정책 (Storage & Logs)

오래된 웹서버 로그로 디스크가 가득 차 서버가 멈추는 문제를 방지하기 위해 logrotate와 du 기반 대용량 폴더 분석기를 제공합니다.

저장 공간 정리 및 Top 폴더 분석 화면 (tab6_storage.png)

주요 기능

  • 자동 로그 보관 스케줄러: 지정한 보관 일수(예: 30일)를 초과한 웹로그는 logrotate로 압축 회전시키고, systemd 저널은 vacuum-time으로 안전하게 비웁니다.
  • 디스크 Top 15 폴더 분석기: 디스크 용량을 많이 차지하고 있는 상위 디렉터리를 용량 순으로 정렬하여 원클릭으로 탐색합니다.

💻 파일 탐색기 & 웹 터미널 (Files & Terminal)

별도의 FTP 프로그램이나 SSH 클라이언트 없이도 웹 브라우저 안에서 파일을 탐색·수정하고 리눅스 셸을 자유롭게 다룰 수 있습니다.

파일 탐색기 및 WebSocket PTY 웹 터미널 (tab7_terminal.png)

주요 기능

  • 1GB 파일 업로드: 브라우저 드래그 앤 드롭으로 대용량 압축 파일이나 소스 코드를 서버로 즉시 전송합니다.
  • 원클릭 압축 해제: .zip, .tar.gz 파일을 서버 내부에서 고속으로 압축 해제합니다.
  • 진짜 PTY 웹 터미널: xterm.js와 portable-pty 기반의 실시간 양방향 WebSocket 터미널로 vim, top, htop 등을 온전하게 실행할 수 있습니다.

보안 감사 로그 페이징 화면 (tab8_security.png)

특징

  • 페이징 최적화: 최근 최대 500건의 로그를 한 페이지당 30건 단위로 나누어 쾌적하게 조회할 수 있습니다.
  • 침입 추적: 비정상 로그인 시도 및 잠금 이력이 고스란히 남아 침해 사고 발생 시 원인을 정확히 추적할 수 있습니다.

🖥️ 멀티 서버 통합 관리 (Multi-Server)

여러 대의 서버(서울 노드, 일본 노드, 개발 서버 등)에 설치된 CHost 패널들을 중앙 패널 하나에 등록하여 실시간으로 상태를 모니터링합니다.

  • 중앙 집중 관제: 각 원격 서버의 CPU, RAM, Disk 사용률, 실행 중인 사이트 개수 및 버전을 한눈에 확인합니다.
  • 원클릭 이동: 원격 패널 바로가기 링크 및 실시간 헬스 상태 갱신을 지원합니다.

☁️ 외부 원격 백업 (S3 / WebDAV)

서버 로컬 디스크 손상이나 화재 등 비상 상황에 대비하여, 백업 파일을 외부 클라우드 스토리지로 안전하게 자동 분산 보관합니다.

원격 백업 설정 화면 (tab10_pro_backup.png)
  • S3 SigV4 순수 구현: AWS S3, Cloudflare R2, MinIO 스토리지로 HMAC-SHA256 암호화 서명을 생성하여 고속 전송합니다.
  • WebDAV 지원: 개인 시놀로지 NAS, QNAP, Nextcloud 스토리지로의 자동 업로드를 지원합니다.
  • 예약 백업 연동: 매일 예약 백업이 끝난 직후 원격 클라우드로 자동 전송되도록 설정할 수 있습니다.

🤖 AI 서버 에러 닥터 (AI Server Doctor)

사이트 접속 불가, 502 Bad Gateway, 데이터베이스 연결 오류 등 복잡한 서버 장애를 인공지능이 즉시 진단하여 명쾌한 해결책을 제시합니다.

AI 서버 에러 닥터 화면 (tab10_pro_ai.png)
  • 내장 규칙 진단 엔진 (무료/기본): 포트 충돌(EADDRINUSE), 502 Bad Gateway, MySQL 인증 실패, 디렉터리 권한 부족, OOM 강제 종료, PHP 문법 에러, Rust 패닉을 수초 내에 분석합니다.
  • OpenAI / Gemini 연동: 보안 설정에서 API 키를 입력하면 최신 로그 맥락까지 LLM이 정밀 분석하여 단계별 조치 가이드를 한국어로 알려줍니다.

↩️ Git 사이트 롤백 센터 (Git Rollback Center)

Git으로 배포된 모든 웹 애플리케이션의 커밋 타임라인을 확인하고, 장애 발생 시 클릭 한 번으로 과거 정상 시점으로 되돌립니다.

Git 사이트 롤백 센터 화면 (tab10_pro_git.png)
  • 원클릭 롤백: 이전 커밋의 [↩️ 롤백] 버튼을 누르면 git reset --hard를 수행하고 앱을 자동으로 다시 빌드·재기동합니다.
  • 무중단 헬스체크: 롤백 중에도 방문자에게 에러 화면 대신 준비 중 안내 화면을 송출하여 안정성을 극대화합니다.

❓ 긴급 복구 CLI 플래그 & FAQ

패널 비밀번호나 OTP 키를 분실했거나, IP 차단으로 패널에 들어갈 수 없을 때 서버 터미널에서 즉시 해결할 수 있는 긴급 복구 명령어입니다.

상황명령어설명
OTP 휴대폰 분실 sudo /opt/chost/chost --reset-2fa 2단계 인증을 즉시 해제하여 일반 비밀번호로 로그인 가능하게 합니다.
IP 화이트리스트 차단 sudo /opt/chost/chost --clear-ip-whitelist IP 제한을 모두 비워 모든 IP에서 패널 접근을 허용합니다.
보안 접속 경로 분실 sudo /opt/chost/chost --show-entry 현재 설정된 비밀 접속 경로 URL을 터미널에 출력합니다. (해제: --reset-entry)
서비스 상태 확인 sudo systemctl status chost CHost 패널 데몬의 실행 상태와 포트 바인딩을 확인합니다.
