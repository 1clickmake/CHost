개발자 문서 (Developer Guide)

CHost 서버 패널의 설치, 소스 빌드, REST API 규격, 다국어 확장 및 보안 설계를 안내합니다.

1. 운영체제별 빠른 설치 (Linux)

install.sh는 아키텍처(x86_64 / ARM64)를 자동 감지하여 /opt/chost에 바이너리를 배치하고 systemd 서비스를 등록합니다.

sudo apt update && sudo apt install -y curl tar
curl -sSL https://raw.githubusercontent.com/1clickmake/CHost/main/install.sh | sudo bash
sudo dnf install -y curl tar epel-release
sudo firewall-cmd --permanent --add-port=8800/tcp && sudo firewall-cmd --reload
curl -sSL https://raw.githubusercontent.com/1clickmake/CHost/main/install.sh | sudo bash
sudo dnf install -y curl tar
curl -sSL https://raw.githubusercontent.com/1clickmake/CHost/main/install.sh | sudo bash
git clone https://github.com/1clickmake/CHost.git && cd CHost
docker run -d --name chost -p 8800:8800 -v $(pwd):/app -w /app ubuntu:24.04 bash -c "apt update && apt install -y curl ca-certificates && ./install.sh && tail -f /dev/null"

설치 완료 후 초기 관리자 비밀번호는 아래 경로에서 확인할 수 있습니다.

cat /var/lib/chost/init_password.txt

CHost 패널 완전 삭제 (Uninstall) — 서비스와 패널 파일만 깔끔하게 제거합니다.

sudo systemctl disable --now chost && sudo rm -rf /etc/systemd/system/chost.service /opt/chost /var/lib/chost && sudo systemctl daemon-reload

웹 루트·로그까지 모두 포함한 완전 초기화 (테스트 서버를 처음 상태로 되돌릴 때 사용)

sudo systemctl disable --now chost && sudo rm -rf /etc/systemd/system/chost.service /opt/chost /var/lib/chost /www/wwwroot /www/wwwlogs && sudo systemctl daemon-reload

2. 소스 코드 빌드 (Rust)

git clone https://github.com/1clickmake/CHost.git
cd CHost
cargo build --release --bin chost
CHOST_PORT=8800 ./target/release/chost

3. 핵심 REST API 레퍼런스

모든 관리 API는 로그인 후 발급되는 chost_token HttpOnly JWT 쿠키로 인증됩니다.

MethodEndpointDescription
POST/api/auth/login관리자 인증 및 JWT 세션 발급
POST/api/auth/change-password패널 로그인 후 관리자 비밀번호 변경
GET/api/system/statsCPU, 메모리, 디스크 사용률(80% 경고) 및 업타임 조회
GET / POST/api/sites도메인 목록 조회 및 /www/wwwroot 사이트 생성 (SSL·FTP/SFTP·DB 자동 발급 지원)
POST/api/sites/subdomain서브도메인·언어·프레임워크·SSL·FTP/SFTP·DB 자동 생성
GET / POST/api/runtimes/status · /install초기 세팅 마법사 & 런타임 스토어(Nginx/Apache2/MariaDB/PHP/Python/Node/Rust/Java) 원클릭 설치
POST/api/sites/{id}/php사이트별 PHP 버전(7.4~8.4) 즉시 전환
POST/api/sites/{id}/sslCertbot 기반 Let's Encrypt SSL 인증서 발급
GET / POST/api/apps언어 프리셋(Rust/Python/Node/PHP) 앱 등록
POST/api/db/sqlite/query내장 멀티 DB 스튜디오 SQL 쿼리 실행
GET / POST/api/storage/scan보관 기간별 로그 스캔(미리보기) 및 안전 정리
GET/api/audits관리자 보안 감사 로그 조회

4. 다국어 (i18n) 사전 구조

locales/ 디렉토리에 JSON 파일을 추가하면 패널 상단 언어 선택기에 즉시 연동할 수 있습니다. 기본 지원 언어는 ko, en, ja, zh-CN, es입니다.

5. 보안 및 안전장치 설계

  • DB 데이터(*.db, /var/lib/mysql) 및 업로드 디렉토리(uploads)는 저장 공간 정리 대상에서 원천 차단됩니다.
  • 로그 정리는 실행 중인 프로세스의 파일 핸들을 유지하기 위해 copytruncate / 로테이션 방식을 기본으로 합니다.
  • 모든 설정 변경, DB 쿼리, 터미널 실행 내역은 audit_logs 테이블에 기록됩니다.

6. 패널 메뉴별 화면 가이드 (실제 화면 캡처 · v0.1.10)

CHost 관리자 패널(기본 포트 8800)의 8개 핵심 메뉴별 기능과 입력 항목 설명입니다. 상단 우측의 버전 배지/업데이트 버튼으로 언제든 GitHub 최신 릴리즈를 원클릭 적용할 수 있습니다.

6-1. 대시보드 (Dashboard)

서버의 실시간 CPU 사용률, 메모리(RAM), 디스크(Disk) 사용량과 진행률 그래프, 서버 가동 시간(Uptime), 설치된 서버 패키지 & 런타임(Nginx/Apache2 실행 상태 포함)을 한눈에 모니터링합니다.

6-2. 사이트 및 도메인 (Sites & Domains) · Conf / Log 통합

  • 통합 생성 폼: 직접 도메인(aaa.com)과 서브도메인(sub.chost.work)을 한 화면에서 전환해 언어·프레임워크·런타임 버전을 설정하며, 활성 웹서버(Nginx / Apache2)에 맞춰 설정이 자동 생성됩니다.
  • Issue SSL & 원클릭 FTP/DB: Let's Encrypt 무료 HTTPS 자동 발급 및 사이트별 FTP/DB 원클릭 생성·조회·수학 퀴즈 안전 삭제를 지원합니다.
  • Conf / Log 모달 & 안전 삭제: 리스트 우측 Conf / Log 버튼으로 추가 도메인, 웹서버 설정 문법 검증 후 저장, PHP 버전 전환, 사이트별 로그 및 웹·DB 용량 확인이 가능합니다.

6-3. 앱 프로세스 (App Processes)

Rust, Python, Node.js, PHP 백그라운드 앱을 등록하고 Start / Stop / Delete 버튼으로 프로세스 상태를 제어합니다.

6-4. 멀티 DB 스튜디오 (Multi-DB Studio)

phpMyAdmin 없이 MariaDB / MySQL(DB 목록, 테이블 조회, SQL 실행, 원클릭 .sql 백업 다운로드)과 SQLite (.db)를 웹에서 안전하게 관리합니다.

6-5. 저장 공간 및 로그 (Storage & Logs)

지정된 일수(7/15/30일) 이전의 오래된 로그 파일을 미리보기 스캔한 뒤 안전하게 압축(.log) 및 정리(.gz/.tmp)합니다. DB 및 업로드 폴더는 자동 보호됩니다.

6-6. 파일 탐색기 및 웹 터미널 (Files & Terminal)

경로를 외우지 않아도 폴더·파일 탐색기에서 클릭 한 번으로 설정 파일을 열어 수정·저장하고, 하단 웹 터미널의 퀵 버튼으로 서버 상태를 즉시 점검합니다.

6-7. 보안 및 감사 로그 (Security & Audit)

페이지 내 관리자 비밀번호 변경, 수학 퀴즈 기반 패널 초기화(가벼운 리셋 / 완전 초기화), 그리고 모든 주요 보안 이벤트의 감사 로그를 시간순으로 추적합니다.

6-8. 런타임 스토어 & 포럼 바로가기 (Runtime Store)

Nginx / Apache2(실행 상태 실시간 구분), MariaDB, Certbot, PHP(7.4~8.3), Python, Node.js, Rust, Java를 선택 설치할 수 있으며, 하단 포럼 바로가기로 커뮤니티 지원 페이지에 즉시 이동합니다.
