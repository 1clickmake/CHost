💡 앱 포트(App Port)란? PHP와 달리 Rust·Python·Node.js·Java 앱은 서버 내부에서 고유 번호(포트)로 실행된 뒤 Nginx가 도메인과 연결해 줍니다. 앱이 사용하는 포트 번호를 입력하세요 (예: Node.js 3000, Python Django 8000, Rust/Spring Boot 8080).

            

              
              
              
            

            

              
              
            

            

              
              
              
            

            
⚠️ 위에서 체크하지 않은 항목(FTP/SFTP, DB)은 사이트 생성 시 세팅되지 않습니다. 게시판(CBoard, 그누보드, 워드프레스 등)을 설치하려면 'Auto Create DB'를 꼭 체크해 주세요! (아이디/비번 입력칸을 비워두면 '도메인명_ftp', '도메인명_db' 이름과 랜덤 비밀번호가 자동 생성됩니다.)

            
💡 고객 도메인(aaa.com) 또는 서브도메인(sub.chost.work) 모두 동일하게 언어·프레임워크·SSL·FTP/SFTP·DB를 한 번에 생성할 수 있습니다.

💡 앱 포트란? 등록한 프로그램이 서버 안에서 대기하는 번호입니다. 사이트 생성 시 입력한 앱 포트와 같은 번호를 넣으면 도메인과 연결됩니다.

SQLite / 멀티 DB 스튜디오

            

              💡 사용법 안내: 별도의 phpMyAdmin 없이 웹에서 안전하게 DB를 조회·백업할 수 있습니다.

              • MariaDB: 사이트와 함께 자동 생성된 DB를 선택하고 테이블 조회 또는 .sql 백업을 다운로드하세요.

              • SQLite: 서버 내 .db 파일 경로를 입력해 테이블과 데이터를 바로 조회합니다. (예: /var/lib/chost/chost.db)
            

            

              
              
            

            

              

                
                
                
              

              

              
              

                
                
              

              

            

            

              

                
                
              

              

              
              

                
                
              

              

            

          

        


        

          

            
로그 및 저장 공간 정리

            

              💡 사용법 안내: 서버 디스크가 오래된 로그로 가득 차는 것을 막아줍니다.

              1) 먼저 [미리보기 스캔]을 눌러 정리 대상 파일과 확보 용량을 확인하세요.

              2) 확인 후 [안전 정리 실행]을 누르면 오래된 .log는 압축하고 .gz/.tmp만 안전하게 정리합니다. (DB 파일과 업로드 폴더는 절대 보호됩니다)
