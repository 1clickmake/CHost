💡 앱 포트(App Port)란? PHP와 달리 Rust·Python·Node.js·Java 앱은 서버 내부에서 고유 번호(포트)로 실행된 뒤 Nginx가 도메인과 연결해 줍니다. 앱이 사용하는 포트 번호를 입력하세요 (예: Node.js 3000, Python Django 8000, Rust/Spring Boot 8080).

            

              
              
              
            

            

              
              
            

            

              
              
              
            

            
⚠️ 위에서 체크하지 않은 항목(FTP/SFTP, DB)은 사이트 생성 시 세팅되지 않습니다. 게시판(CBoard, 그누보드, 워드프레스 등)을 설치하려면 'Auto Create DB'를 꼭 체크해 주세요! (아이디/비번 입력칸을 비워두면 '도메인명_ftp', '도메인명_db' 이름과 랜덤 비밀번호가 자동 생성됩니다.)

            
💡 고객 도메인(aaa.com) 또는 서브도메인(sub.chost.work) 모두 동일하게 언어·프레임워크·SSL·FTP/SFTP·DB를 한 번에 생성할 수 있습니다.
