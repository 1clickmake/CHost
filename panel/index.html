💡 앱 포트(App Port)란? PHP와 달리 Rust·Python·Node.js·Java 앱은 서버 내부에서 고유 번호(포트)로 실행된 뒤 Nginx가 도메인과 연결해 줍니다. 앱이 사용하는 포트 번호를 입력하세요 (예: Node.js 3000, Python Django 8000, Rust/Spring Boot 8080).

            

              
              
              
            

            

              
              
            

            

              
              
              
            

            
⚠️ 위에서 체크하지 않은 항목(FTP/SFTP, DB)은 사이트 생성 시 세팅되지 않습니다. 게시판(CBoard, 그누보드, 워드프레스 등)을 설치하려면 'Auto Create DB'를 꼭 체크해 주세요! (아이디/비번 입력칸을 비워두면 '도메인명_ftp', '도메인명_db' 이름과 랜덤 비밀번호가 자동 생성됩니다.)

            
💡 고객 도메인(aaa.com) 또는 서브도메인(sub.chost.work) 모두 동일하게 언어·프레임워크·SSL·FTP/SFTP·DB를 한 번에 생성할 수 있습니다.

SQLite / 멀티 DB 스튜디오

            

              💡 사용법 안내: 별도의 phpMyAdmin 없이 웹에서 안전하게 DB를 조회·백업할 수 있습니다.

              • MariaDB: 사이트와 함께 자동 생성된 DB를 선택하고 테이블 조회 또는 .sql 백업을 다운로드하세요.

              • SQLite: 서버 내 .db 파일 경로를 입력해 테이블과 데이터를 바로 조회합니다. (예: /var/lib/chost/chost.db)

💾 예약 자동 백업

            
💡 매일 정해진 시각에 모든 DB(MariaDB·PostgreSQL)와 사이트 파일, CHost 설정을 /www/backup 에 압축 보관합니다. (node_modules·빌드 폴더·.git 제외) 오래된 백업은 보관 개수만큼만 남기고 자동 정리됩니다.

            

              
              
              
              
              
            

            

            

          

          

            
☁️ 외부 원격 백업 (S3 / WebDAV)

            
💡 로컬 백업(/www/backup)을 AWS S3·Cloudflare R2·MinIO 또는 WebDAV 스토리지로 안전하게 원격 전송합니다. 자동 전송을 켜면 예약 백업 완료 후 바로 업로드됩니다.

            

              
              
              
            

            

              
              
            

            

              
              
            

            

              
              
            

            

            

              
              
              
            

          

        


        

          

            
로그 및 저장 공간 정리

            

              💡 사용법 안내: 서버 디스크가 오래된 로그로 가득 차는 것을 막아줍니다.

              1) 먼저 [미리보기 스캔]을 눌러 정리 대상 파일과 확보 용량을 확인하세요.

              2) 확인 후 [안전 정리 실행]을 누르면 오래된 .log는 압축하고 .gz/.tmp만 안전하게 정리합니다. (DB 파일과 업로드 폴더는 절대 보호됩니다)
            

            

              
              
              
            

            

          

          

            
🗓️ 로그 보관 정책 (자동)

            
💡 켜 두면 사이트 로그(/www/wwwlogs)를 매일 나눠 압축하고(logrotate, 실행 중인 로그도 안전하게 copytruncate), 매일 새벽 4시에 보관 기간이 지난 로그와 시스템 저널을 자동으로 정리합니다. DB·업로드 폴더는 건드리지 않아요.

            

              
              
              
              
            

            

          

          

            
🔎 디스크 용량 분석

            
💡 어떤 폴더가 디스크를 많이 차지하는지 큰 순서대로 보여줍니다. 폴더 이름을 누르면 그 안으로 들어가요. (디스크가 크면 몇십 초 걸릴 수 있어요)

(설정 파일 수정 전에는 내용을 확인하고 저장하세요)

⚙️  사이트 설정 (Conf / Log)

    

    

      

        
        
        
        
        
        
      

      

        

          
💡 기본 도메인 외에 연결할 추가 도메인(예: www.example.com)을 한 줄에 하나씩 입력해 저장하세요.

          
          

        

        

          
💡 웹서버 설정(server / VirtualHost)을 직접 수정합니다. 저장 시 문법 검사 통과 후에만 적용되므로 오타가 나도 서버가 죽지 않습니다.

          
          

        

        

          
💡 PHP 사이트의 버전을 즉시 전환합니다. (구형 그누보드는 7.4, 최신 사이트는 8.3 권장)

          

            
            
          

          

            
💡 선택한 PHP 버전의 핵심 옵션을 바로 수정합니다. (같은 버전을 쓰는 모든 사이트에 적용 · 업로드 용량 등)

            

              
              
              
              
            

            

          

        

        

          
💡 Let's Encrypt 무료 HTTPS 인증서 상태를 확인하고 발급·갱신할 수 있습니다.
